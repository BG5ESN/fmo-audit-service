EMQX 连接（步骤 2）
API 密钥获取方法：EMQX Dashboard → 管理（系统设置）→ API 密钥 → 新建密钥
· 名称随意填写，角色选择 administrator（如自定义权限需包含：客户端、连接、黑名单等范围）
· 创建后立即复制 api_key 与 api_secret——secret 只显示一次，丢失需重新创建
· ⚠️ Dashboard 的登录账号（admin）不能调用 API，必须使用 API 密钥

Webhook 地址：
数据流向：主题统计由 EMQX 规则引擎主动上报到本工具（Webhook 推送），而非本工具去 EMQX 查询——因此 Webhook 地址必须对 EMQX 所有节点可见。
· 同局域网：用上方 IP 按钮快速选择本机地址即可
· 异地集群：需手动改为所有节点可达的地址（公网域名或 IP:port），否则节点无法上报、主题统计无数据
· 公网地址：建议套 HTTPS 反代并在反代层限制来源（仅允许 EMQX 节点 IP）
启用后自动在 EMQX 上创建规则引擎（连接器 emqx-monitor-ingest + 规则），只统计该主题下的消息，其他主题不采集。
